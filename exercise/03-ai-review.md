# งานที่ 3: ให้ AI รีวิว ADR (ประมาณ 5 นาที)

> **เชื่อมโยงกับการบรรยาย:** P5 การทำงานร่วมกันระหว่างมนุษย์กับ AI โดย AI รับบทเป็น *Chief Analyst* งานวิจัยปี 2026 พบว่า LLM มักทำได้เท่าหรือดีกว่าทีมนักศึกษาในการหาความเสี่ยงและ trade-off แบบ ATAM ([arXiv 2603.28914](https://arxiv.org/abs/2603.28914)) ส่วน B จะทดสอบข้ออ้างนี้

เริ่มแชตหรือ session ใหม่ แล้วส่งข้อความด้านล่าง โดยใส่ path ของ **ADR ฉบับสุดท้ายของนิสิต**

```
Follow prompts/3-review-adr.md
adr: docs/adr/0002-<your-title>.md
language: Thai
```

บรรทัด `language: Thai` ทำให้ผลรีวิวเป็นภาษาไทย (ประเภทของข้อค้นพบ เช่น Risk, Trade-off point ยังคงเป็นภาษาอังกฤษ) หากต้องการภาษาอังกฤษให้ลบบรรทัดนี้

agent จะเขียนผลรีวิวแบบ ATAM ความยาวหนึ่งหน้าไว้ที่ [`outputs/3-review.md`](outputs/3-review.md) agent ต้องไม่แก้ไข ADR ของนิสิต หากแก้ไข ให้ปฏิเสธหรือ undo การเปลี่ยนแปลงนั้น

**ยังไม่ต้องแก้ไขตามผลรีวิว** ให้อ่าน commit และนำไปใช้ในที่ประชุมคณะกรรมการรีวิวในส่วน B คณะกรรมการจะเป็นผู้ตัดสินว่าข้อค้นพบใดสำคัญ

> **หมายเหตุของนิสิต:** ส่งข้อความด้วย `adr: docs/adr/0002-publish-order-placed-event-to-rabbitmq.md` เป็นภาษาอังกฤษ (ไม่ใส่ `language: Thai`) agent อ่านเฉพาะ ADR และ `docs/scenario.md` ตามที่อนุญาต และไม่ได้แก้ ADR (ตรวจด้วย timestamp และ diff แล้ว) คำตัดสิน: **Accept with changes** พร้อมเงื่อนไข 3 ข้อ

- **ความประทับใจแรกต่อผลรีวิวของ AI** (หนึ่งประโยค): รีวิวนี้เจาะจุดที่ฉันเพิ่งตัดสินใจเองได้แม่นอย่างน่าตกใจ โดยเฉพาะการชี้ว่า "manual replay" ของฉันจะทำให้ PII ของ 12,000 ออเดอร์ต่อนาทีไหลลง log และ TTL ที่ฉันเพิ่มเพื่อความเป็นส่วนตัวกลับทำลาย exactly-once ของ loyalty ซึ่งทั้งสองเป็นผลข้างเคียงจากการแก้ไขของฉันเอง ไม่ใช่ของร่าง AI
